# Campus Event Management System

This project is a lightweight front-end prototype for an online campus event catalog and registration flow.

## Structure

- `index.html` — page shell and modal container
- `css/` — modular styles separated by responsibility
- `js/` — modular JavaScript for data, state, UI, and validation

## Features

- searchable and filterable event catalog
- event details modal
- registration form with validation
- accessible form fields and keyboard-friendly interactions
- responsive layout for desktop and mobile

## Run locally

From the project folder, use:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000
